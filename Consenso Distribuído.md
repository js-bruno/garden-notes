# Consenso Distribuído

Consenso é o processo de fazer vários nós concordarem sobre uma decisão, mesmo quando alguns nós falham.

Um caso comum é eleger um líder para receber operações. Os outros nós acompanham esse líder e podem assumir seu lugar se ele falhar.

Este é um assunto difícil. Nesta primeira passagem, o objetivo é entender o problema antes de estudar algoritmos como Raft.
