# Sistema Distribuído

Um sistema distribuído é formado por vários computadores que trabalham juntos e aparecem para o usuário como um sistema único.

Exemplos: sites, bancos de dados replicados, filas e serviços de mensagens.

O desafio é que a rede pode falhar, as máquinas podem ter horários diferentes e uma mensagem pode demorar ou desaparecer.
